## Sobre Fixtergeek - Historia y Fundador

Fixtergeek es una plataforma educativa mexicana fundada en 2016 por Héctor Bliss, especializada en programación, inteligencia artificial y herramientas modernas de desarrollo. Con más de 8 años de experiencia enseñando tecnología, Héctor Bliss se ha convertido en un pionero en hacer la IA accesible para desarrolladores de habla hispana. La plataforma ha formado a más de 2,000 estudiantes activos que ahora trabajan en empresas de tecnología líderes como Google, Mercado Libre, HSBC, Santander, Cisco y otras compañías internacionales. El enfoque de Fixtergeek es transformar el aprendizaje técnico en una experiencia entretenida y práctica, alejándose de la teoría excesiva para enfocarse en proyectos reales que los desarrolladores pueden aplicar inmediatamente en su trabajo diario.

## Filosofía Educativa - Hacking Yourself

La filosofía de Fixtergeek se resume en "Hacking Yourself", un concepto que invita a los estudiantes a hackear sus propias limitaciones y creencias sobre el aprendizaje de programación. El enfoque pedagógico combina video lecciones de alta calidad, recursos adicionales descargables y feedback de la comunidad para crear contenido práctico y entretenido. A diferencia de otras plataformas que se enfocan en certificaciones o contenido teórico extenso, Fixtergeek prioriza que los estudiantes construyan proyectos funcionales desde la primera clase. Cada curso está diseñado para que el estudiante pueda aplicar lo aprendido en su trabajo o proyectos personales de manera inmediata. La metodología incluye ejercicios prácticos, código fuente disponible para descargar, y acceso a una comunidad activa de desarrolladores que comparten experiencias y se ayudan mutuamente.

## Stack Tecnológico y Lenguajes

Fixtergeek cubre un amplio espectro de tecnologías modernas para desarrollo web y aplicaciones de inteligencia artificial. En el frontend, los cursos abarcan React como framework principal, junto con TypeScript para tipado estático, Tailwind CSS para estilos utilitarios, y Motion (anteriormente Framer Motion) para animaciones fluidas. En el backend, se enseña Node.js como entorno de ejecución, Express para APIs REST, y MongoDB como base de datos NoSQL. Para autenticación y servicios en la nube, Firebase es la herramienta principal enseñada. Adicionalmente, la plataforma ha incorporado tecnologías emergentes como Rust para desarrollo de sistemas, Docker para containerización, y Python para scripts de automatización y machine learning. En el área de IA, los cursos cubren AI SDK de Vercel, Claude Code de Anthropic, OpenAI API, y Gemini de Google.

## Curso: AI SDK con React y TypeScript

El curso más reciente de Fixtergeek es el taller de AI SDK con React y TypeScript, diseñado para desarrolladores que quieren integrar inteligencia artificial en aplicaciones web modernas. Este workshop práctico de 7 horas totales se divide en 2 sesiones de 3.5 horas cada una, realizadas los sábados en formato de taller en vivo con grupos reducidos para máxima interacción. La primera sesión cubre los fundamentos: configuración del entorno, conceptos core del AI SDK, streaming básico con Express y JavaScript vanilla, implementación en React usando el hook useChat, herramientas (tools) y UI generativa con componentes dinámicos. La segunda sesión avanza a temas más complejos: repaso rápido de fundamentos, integración de subida de archivos para contexto documental, implementación de RAG con embeddings para búsqueda por similitud semántica, y sesión de preguntas con recursos adicionales. El precio regular es de $4,990 MXN pero frecuentemente hay descuentos del 25% quedando en $3,742.50 MXN. Incluye código fuente, sesiones en vivo grabadas, y acceso permanente al material.

## Curso: Power-User en Claude Code

El curso de Claude Code está diseñado para desarrolladores que quieren dominar completamente las capacidades de Claude Code, el CLI oficial de Anthropic para programación asistida por IA. Este curso avanzado de 8 horas está estructurado en 4 sesiones de 2 horas cada una. La Sesión 1 cubre fundamentos y gestión de contexto: configuración profesional de Claude Code, arquitectura de prompts efectivos, gestión avanzada de contexto con el comando /resume, y optimización de tokens y memoria. La Sesión 2 se enfoca en SDK, subagentes y scripting: Claude SDK para Python y TypeScript, subagentes y delegación de tareas, agentes Nano y Banana para tareas especializadas, scripting con TypeScript y Python, y pipelines CI/CD con casos empresariales reales. La Sesión 3 trata MCP y automatización: configuración de MCP (Model Context Protocol) con JSON sin necesidad de programar, GitHub MCP para integración con repositorios, automatización con GitHub Actions, y conexión a bases de datos y APIs externas. La Sesión 4 culmina con orquestación de agentes: arquitectura multi-agente, coordinación entre agentes, patrones avanzados de comunicación, y un proyecto final llamado "Cerebro Maestro Corporativo". El curso pregrabado cuesta $1,490 MXN mientras que el taller en vivo tiene un precio de $3,499 MXN.

## Curso: Agentes de IA Sin Código

Este taller premium está diseñado para quienes quieren crear agentes de inteligencia artificial sin necesidad de programar, utilizando herramientas visuales drag-and-drop. El curso de 8 horas enseña a construir agentes inteligentes que pueden interactuar con APIs, procesar documentos y automatizar tareas complejas. Los proyectos prácticos incluyen: un Chatbot con Memoria que mantiene el contexto de conversaciones largas, un Asistente de Restaurante que consulta menús, calcula precios y agenda reservas automáticamente, un Estudio Fotográfico Automático que genera variantes de imágenes con poses profesionales usando nano-banana, y un sistema RAG Empresarial que domina documentos corporativos y políticas internas. Las tecnologías utilizadas incluyen modelos como GPT-5, Claude y Gemini, accesibles a través de Visual-ai-builder.app, una plataforma no-code. El taller incluye un servidor personal para cada estudiante. La primera sesión es completamente gratuita y permite crear tu primer agente en 30 minutos. El taller completo de 4 sesiones tiene un precio de $4,900 MXN. Los únicos requisitos son una computadora, navegador moderno y conexión a internet.

## Curso: Animaciones con React y Motion

El curso de animaciones con React y Motion es uno de los más extensos de la plataforma, con 600 minutos (10 horas) de contenido donde los estudiantes construyen más de 14 componentes animados profesionales. Este curso de nivel intermedio enseña a crear interfaces de usuario dinámicas y atractivas utilizando Motion (la nueva versión de Framer Motion) junto con React. Los componentes que se construyen incluyen: botones con micro-interacciones, menús desplegables animados, modales con transiciones suaves, carruseles de imágenes, accordions expandibles, tabs con indicador animado, tooltips contextuales, notificaciones toast, skeleton loaders, transiciones de página, animaciones de scroll, gestos táctiles, layouts compartidos, y efectos de stagger para listas. Cada componente está diseñado para ser reutilizable y personalizable, con código limpio que sigue las mejores prácticas de React. El curso incluye explicaciones detalladas de los conceptos de animación como spring physics, keyframes, variants, y orchestration de animaciones complejas.

## Cursos Gratuitos Disponibles

Fixtergeek ofrece varios recursos gratuitos para estudiantes que quieren comenzar su aprendizaje sin inversión inicial. El curso "Introducción al Desarrollo Web Full Stack con React Router" de 60 minutos está dirigido a principiantes y enseña los fundamentos de crear aplicaciones web completas usando React Router v7. Este curso gratuito cubre routing del lado del cliente, loaders para carga de datos, actions para mutaciones, y despliegue básico. Otro curso gratuito es "Intro a las Aplicaciones Fullstack con React y Remix" de 60 minutos, también para principiantes, que explora el framework Remix para crear aplicaciones web con renderizado del lado del servidor. Además de los cursos, hay dos eBooks gratuitos disponibles para descarga: "Domina Claude Code" que es una guía completa para sacar el máximo provecho del CLI de Anthropic, y "LlamaIndex Agent Workflows" que explica cómo construir flujos de trabajo con agentes usando LlamaIndex. Los tutoriales de la plataforma, actualmente en actualización, ofrecen ejercicios de lógica y algoritmos para practicar programación.
